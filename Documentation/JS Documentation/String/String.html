Strings Cheat Sheet

1. Strings are Immutable

النصوص في جافاسكريبت غير قابلة للتعديل؛ كل دوال النصوص مثل replace، trim، slice، toUpperCase ترجع نصاً جديداً تماماً ولا تُغيّر المتغير الأصلي.

2. at() vs charAt()

• at(-1): يدعم الأرقام السالبة للوصول لآخر حرف بسهولة.
• charAt(): لا يقبل أرقاماً سالبة، ويرجع نصاً فارغاً "" لو كان الـ Index غير موجود.

3. slice() vs substring()

• slice(start, end): يقبل القيم السالبة (يحسب من اليمين).
• substring(start, end): لا يقبل السالب (يعتبره 0)، وإذا كان start أكبر من end يعكس الترتيب تلقائياً.

4. indexOf() vs search()

• indexOf(val, startPos): يبحث عن نص صريح ويقبل موقع بدء العد.
• search(RegExp): يدعم التعابير النمطية (Regex) مثل /locate/i.
