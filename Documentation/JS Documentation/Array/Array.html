Arrays & Memory Overview

Reference vs Value (Stack vs Heap)

المتغير في الـ Stack يحمل فقط عنوان الذاكرة (Memory Address) المشير إلى مكان الـ Array في الـ Heap. المقارنة بـ === تقارن العناوين وليس المحتوى.

The Single Number Trap

new Array(5) ينشئ Sparse Array بطول 5 وفراغات فارغة (Empty slots)، بينما [5] ينشئ مصفوفة تحتوي على الرقم 5.

Shallow Copy vs Direct Reference

slice() تصنع نسخة جديدة بعنوان مستقل في الـ Heap، بينما foods2 = foods تنسخ نفس العنوان، وأي تعديل سيؤثر على الاثنين.

Mutating Methods vs Non-Mutating

تعدل المصفوفة الأصلية: push, pop, shift, unshift, splice.
لا تعدل الأصلية (تُرجع قيمة/مصفوفة جديدة): slice, concat, join.
