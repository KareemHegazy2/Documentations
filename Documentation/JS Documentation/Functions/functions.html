Functions Cheat Sheet

1. Expression Function

تخزين الدالة داخل متغير: const minus = function(x, y) {...}

2. Recursion (الاستدعاء الذاتي)

دالة تستدعي نفسها لتقسيم مشكلة كبيرة لخطوات متكررة، مع وجود Base Case إلزامي لمنع الـ Infinite Loop والانهيار:
n * factorial(n - 1)

3. Higher-Order / Returning a Function

إرجاع دالة من دالة أخرى (Function Factory) هو مفهوم مختلف عن الـ Recursion؛ لأنه يُرجع دالة جديدة للمستخدم بدلاً من استدعاء نفسه.

4. Callback Function

تمرير دالة كاملة كـ parameter لدالة أخرى لتشغيلها لاحقاً، مثل تمرير print داخل cars.forEach(print).
