Loops & Flow Control Guide

1. Block Scope (let vs var in loop)

let تخلق نطاقاً مستقلاً (Block Scope) داخل كل لفة من اللوب، بينما var تنتمي لنطاق الـ Function أو الـ Global، لذا تسرب قيمتها النهائية إلى خارج اللوب.

2. For..of vs While vs Do..While

• for..of: أسهل وأوضح طريقة للمرور على عناصر الـ Arrays مباشرة بدون عداد.
• while: تفحص الشرط أولاً، وقد لا تنفذ الكود إطلاقاً لو الشرط false.
• do..while: تضمن تشغيل الكود مرة واحدة على الأقل قبل فحص الشرط.

3. Break vs Continue

• break: ينهي اللوب بالكامل ويخرج منها فوراً.
• continue: يتخطى بقية الكود في اللفة الحالية فقط، وينتقل مباشرة للفة التالية.

4. Labeled Statements (التحكم باللوب المتداخل)

استخدام continue loop1; يتيح لك القفز من داخل الـ Inner Loop مباشرة إلى اللفة التالية في الـ Outer Loop دون إكمال بقية اللفات الداخلية.
