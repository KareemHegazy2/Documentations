Hoisting & Execution Context

1. مرحلة التجهيز (Creation Phase)

المتصفح يقرأ الكود قبل تنفيذه:
• متغيرات var: تُحجز في الذاكرة وتأخذ مبدئياً undefined.
• الـ Function Declaration: تُرفع كاملة (الاسم والكود بالكامل)، لذلك تستطيع استدعاءها قبل كتابتها في الكود.

2. فخ الـ Function Expression

عند كتابة var Hello = function() {...}، المتصفح في مرحلة التجهيز يرفع var Hello = undefined فقط، ولا يعرف أنها دالة إلا في مرحلة التنفيذ.
لذلك استدعاء Hello() قبل سطر التعريف يعطي خطأ TypeError: Hello is not a function.

3. كائن الـ arguments داخل الدالة

arguments هو كائن شبيه بالمصفوفة (Array-like Object) يحتوي على كل القيم الممررة للدالة، وهو سبب نجاح دالة sum(5, 1, 2) في جمع الأرقام رغم عدم تحديد Parameters بين القوسين.
