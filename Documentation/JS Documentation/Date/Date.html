Date Object Guide

Zero-Indexed Months (فخ الشهور)

الشهور في جافاسكريبت تبدأ من 0 (يناير = 0، أغسطس = 7، ديسمبر = 11). لذلك getMonth() في أغسطس ترجع 7.

getDate() vs getDay()

getDate(): يرجع رقم يوم الشهر (1 إلى 31).
getDay(): يرجع ترتيب يوم الأسبوع (الأحد = 0، الإثنين = 1، ...).

setFullYear() والـ Milliseconds

دوال التعديل (Setters) مثل setFullYear تقوم بتعديل كائن التاريخ نفسه، وترجع الـ Epoch Timestamp (عدد المللي ثانية منذ 1 يناير 1970).

ملاحظة على getFullYear()

الدالة getFullYear() لا تأخذ أي معاملات (Arguments)، وإذا مررت لها رقماً يتم تجاهله وترجع فقط السنة المحفوظة داخل الكائن الحالي.
