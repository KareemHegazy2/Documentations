Conditions & Flow Notes

var vs let vs const

var: يقبل Redeclare و Reassign.
let: لا يقبل Redeclare، يقبل Reassign.
const: لا يقبل Redeclare ولا Reassign.

if / else if / else

التنفيذ من الأعلى لأسفل؛ أول شرط يتحقق (true) ينفذ كوده ثم يخرج من الكتلة البرمجية فوراً ولا يكمل فحص الباقي.

Ternary Operator

صيغة مختصرة لـ if...else تأخذ 3 أطراف:
condition ? if_true : if_false

Switch Strict Equality (===)

الـ switch تقارن بـ Strict Comparison؛ لذلك حالة x = "0" لن تطابق case 0 (لأن النوع String وليس Number)، وستذهب للـ default.

Nullish Coalescing (??)

يعوض القيمة فقط إذا كانت null أو undefined، عكس || التي تعتبر 0 و "" و false قيماً باطلة.
